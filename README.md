# OS Design Store

نسخة متجر تصميم كاملة مبنية على Frontend + Backend.

## التشغيل
1. ثبّت Node.js (يفضل 18+).
2. افتح الطرفية داخل مجلد `backend`.
3. نفّذ: `npm install`
4. انسخ `.env.example` إلى `.env` ويمكنك تغيير كلمة مرور الإدارة.
5. نفّذ: `npm start`
6. افتح: `http://localhost:5000`
7. لوحة الإدارة: `http://localhost:5000/admin.html`

## دخول الإدارة الافتراضي
- Username: `admin`
- Password: `change-me-123`

غيّر كلمة المرور في `.env` قبل النشر.

## الصور
الصور التجريبية موجودة في `frontend/images/` ويمكن استبدالها بصورك مع الحفاظ على أسماء الملفات أو تعديل مسار الصورة من لوحة الإدارة.

## ما تم تضمينه
- متجر منتجات من API حقيقي.
- بحث وتصنيف المنتجات.
- طلبات تُحفظ في Backend.
- رقم طلب وتتبع حالة الطلب.
- إرسال الطلب إلى واتساب.
- نموذج رسائل محفوظ في Backend.
- لوحة إدارة للمنتجات والطلبات والرسائل.
- رفع صور من لوحة الإدارة.
- وضع ليلي/فاتح وتصميم متجاوب.
- تخزين محلي JSON لا يحتاج MongoDB.

## ملاحظة
بوابة الدفع الإلكتروني غير مربوطة لأنها تحتاج حسابًا ومفاتيح API خاصة بمزود الدفع. البنية الحالية جاهزة لإضافة الدفع لاحقًا.
